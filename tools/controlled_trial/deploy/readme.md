# 加固后五状态受控对照 — 2026-11-01

目的：在此次加固后的同一安装下采集主模型所需基线与三个试重点，并用最后一份无试重记录观察整轮漂移。只采五份，不因CV10%补测。旧C三次不拼入本模型，主算法不换。

## 开始前与角度定义

风扇断电停转，传感器、支架、底座和线缆保持固定。脚本会先让你选择一直用于数叶片的观察面：1=能看到电机标签和固定支撑筋的一面，2=另一面。

以当前C胶带所在的原叶片标为p0（0°）。从所选观察面看，沿顺时针在九片叶片上数：当前片是第1片p0、第4片p120、第7片p240。标签跟随叶片，固定支撑筋不参与编号；不把这些新角度当作旧A/B/C身份重命名。

开始任何采集前，先用尺在三处标出胶带中心约40mm半径的定位点，所有标记保留在整个批次。试重都用当前这一片胶带，贴原来的同一面，中心对齐标记、平整贴合。第一份前先取下并完整保留该片，不能换另一片冒充同一质量。若明显缺损、卷边、粘不牢或操作碰动安装，输入STOP结束，已有数据会保留。

## 运行

```bash
sudo mkdir -p /mnt/hxusb
mountpoint -q /mnt/hxusb || sudo mount -L MOCLIFFOOD /mnt/hxusb
sudo bash /mnt/hxusb/hx_control_20261101_01/start_control_5.sh
```

跟随提示设置五个状态：无试重前基线、p0、p120、p240、无试重后基线。每次设置好输入大写READY；开风扇后回车，统一等30秒采40秒并分析，随后按提示关风扇等完全停转再回车。每份保留全部8×128圈Z轴AA窗口、实际配置/启动身份和原始停止证据。30秒不是热稳态保证，转速和漂移由数据报告。

当前胶带绝对质量未知，保持null；不填虚构克数或自动输出可实施配重。先用同批数据检查原平方幅值模型，primary baseline固定为第一份，最后一份只作漂移旁证，不能挑闭合更好的基线或换窗。若质量仍未知，绝对修正克数待补证。

软件使用已验证的原工具ZIP，固定PYNQ venv，解压至RAM，新数据只写USB。没有新的FPGA幅值计算、没有自动重试或新增采集。错误即停，先给风扇断电停转，保留部分结果并尝试归档；不要删除已存在的输出或盲目重跑。

结束回到命令提示符后：

```bash
sudo umount /mnt/hxusb
```

U盘回电脑，一次回传CONTROL汇总和归档SHA256。本批结束时风扇断电、试重不在叶片上。修正量及修正后独立减振验证另行依据本批证据决定，未自动完成。
